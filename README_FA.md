# Persian Radio Manager

### مدیریت آسان رادیوهای فارسی برای
### Euro Truck Simulator 2 & American Truck Simulator

</div>

---

## 🎙 معرفی

Persian Radio Manager یک نرم‌افزار رایگان و متن‌باز است که نصب، بروزرسانی، تهیه نسخه پشتیبان و مدیریت **Persian Radio Pack** را برای بازی‌های **Euro Truck Simulator 2** و **American Truck Simulator** بسیار ساده می‌کند.

هدف این پروژه این است که کاربران تنها با چند کلیک بتوانند آخرین نسخه رادیوها را دریافت و نصب کنند.
